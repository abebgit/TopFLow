# MCR-SVC-Based Voltage Regulation Study
This repository contains the source code and sample input spreadsheet used to evaluate and optimize reactive power compensation in a wind farm equipped with a Magnetically Controlled Reactor-Static Var Compensator (MCR-SVC) system. The analysis is based on steady-state power flow simulations using operational SCADA data collected between 2023 and 2024.

### Associated Publication
This repository supports the following publication:

"Data-Driven Modeling and Optimal Compensation of FACTS Devices for Real-World Performance Assessment in the Adama-II Wind Farm"

[Currently Under Review]
